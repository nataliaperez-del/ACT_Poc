# ACTiva Arte

Prototipo del proyecto de investigación “Integración de la terapia de aceptación y compromiso (ACT) con el arte mediado por tecnología como estrategia para mejorar el bienestar psicológico de estudiantes en situación de vulnerabilidad en el sector rural del CCAV de Facatativá”, código PIS146ZCBOGECBTIECSAH2026.

Herramienta de mediación tecnológica, basada en Terapia de Aceptación y Compromiso (ACT), que ofrece seis actividades guiadas —una por cada proceso del hexaflex— con expresión artística y seguimiento del progreso. No reemplaza la terapia psicológica ni el tratamiento médico.

## Uso

El aplicativo es un único archivo, [`index.html`](index.html), sin dependencias de compilación ni servidor. Se puede abrir directamente en un navegador (se recomienda Chrome o Edge) o desplegar como sitio estático. Funciona sin conexión; las tipografías se cargan desde Google Fonts cuando hay conexión.

Perfiles: estudiante (con consentimiento informado), docente y administrador (con PIN).
